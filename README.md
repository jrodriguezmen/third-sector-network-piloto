# Red de Tercer Sector - Piloto

## Descripción

Plataforma web demostrativa para conectar organizaciones del tercer sector, facilitando la visualización de proyectos sociales y fomentando la colaboración entre entidades.

Esta es una versión piloto compatible con despliegue directo en Vercel y otras plataformas de hosting estático.

## Características

- **Interfaz responsive**: Adaptada para dispositivos móviles y desktop
- **Carga dinámica de proyectos**: Los proyectos se cargan desde un archivo JSON
- **Diseño moderno**: Utiliza gradientes y animaciones CSS
- **Compatible con Vercel**: Estructura lista para despliegue inmediato

## Estructura del Proyecto

```
third-sector-network-piloto/
├── index.html                     # Página principal
├── style.css                      # Estilos de la aplicación
├── app.js                         # Lógica JavaScript
├── proyectos_piloto_3sn.json     # Datos de proyectos de ejemplo
└── README.md                      # Este archivo
```

## Despliegue en Vercel

1. Conecta este repositorio con tu cuenta de Vercel
2. Configura el proyecto (Vercel detectará automáticamente la configuración)
3. Despliega con un clic

## Tecnologías Utilizadas

- HTML5
- CSS3 (con Grid y Flexbox)
- JavaScript ES6+ (Fetch API)
- JSON para datos
